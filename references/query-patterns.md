# 搜索式模板

## 拼装公式

```
{行业词} + {动作词} + {时间/地点限定}
```

三样缺一样，质量掉一半：只有行业词 → 搜到企业名录、招聘、展会；只有动作词 → 搜到泛财经；没有时间限定 → 搜到三年前的旧闻。

---

## 七类模板（② 政府公示、④ 财经媒体、⑤ 项目立项库 三类必跑，其余按需）

### ① 扩产动作（主力，出量最多）

```
{产品} 年产 {数量} 万台 项目 开工
{产品} 新工厂 投产 2026
{产品} 新基地 奠基 2026
{产品} 产线 技改 扩能 2026
{产品} 试产 量产 下线 2026
```

### ② 政府公示（质量最高）

```
{产品} 重大建设项目 公示 {省/市}
{产品} 投资项目备案 {省/市} 2026
{产品} 重点项目 开工 园区 2026
```

最容易被忽略，但信息最实：投资额、占地、建设起止时间、产能数字都有。这些散落在各县区政府网站的公示栏目里，只有搜索引擎能带出来。

### ③ 上市公司公告

```
{产品} 募投项目 公告
{产品} 增资 建设基地 公告
{产品} 技改项目 公告
```

公司名、业务、动作三样齐，但只覆盖上市公司。

### ④ 财经媒体口径（覆盖在建产线，必跑）

```
{产品} 在建 产线 投产 计划
{产品} 投资者交流 产能 扩产
{产品} 事业部 新厂 进度 2026
{产品} 预计 2027 投产 项目
```

这一类补的是前两类共同的盲区：**厂房还在建、尚未出现在政府公示与上市公司公告里的产能项目**。它们只出现在财经媒体、投资者关系记录、行业调研稿里。

实测反例：某机器人驱控企业 1 月启动基建、当前租厂房建无框电机工厂，只在 11 月投资者交流中披露——政府公示口径一条都搜不到，而它是那批结果里最该跟的一条。

注意：财经媒体的标题很少带完整公司名，多为「XX 公司」「拟投资」，读正文确认主体，别只看标题就判。

### ⑤ 项目立项库口径（最早，必跑）

```
{产品} 项目 立项 计划开工 {省/市}
{产品} 建设项目 审批 {年份}
{产品} 项目 总投资 设备投资 {省}
```

这类是**按「立项 / 计划开工」结构化收录的项目库**（各地投资项目审批库、工程信息平台、行业项目库）。它们在备案当天就收录，比政府公示页和新闻稿更早，而且常带「计划开工时间」「设备投资额」这两项最有用的字段。

实测本轮排名前两位的线索全部来自这类源：一条是「年产 28 万台水泵、计划开工 11 月」，一条是「年产 4 万台套泵、计划开工 10 月」，都是新闻里搜不到、政府公示页也还没挂的。

⚠️ 两个必须核实：**页面的「更新时间」不是事件时间**；**「计划开工」经常延后**。这类条目不精读就不要上台面。

### ⑥ 中标 / 设备更新

```
{产品} 生产线 中标 2026
{产品} 设备更新 采购 中标
```

中标公告主体是**采购人（甲方）**，不是造设备的。只在能确认中标人是制造企业时才用。

### ⑦ 追单家（第二轮）

```
{公司名} 扩产
{公司名} 二期 投产
{公司名} 新产线
```

对已上台面的线索做二次确认，比反复搜泛词有效。

## 动作词表（按强度排序）

**strong（优先）**：扩产、投产、达产、新产线、下线、开工、奠基、产能爬坡、募投、中标、签约、首台套、设备更新、以旧换新、产业园、试产、量产、技改、新建、扩能、量产交付、首批交付、开启交付、新品发布、全球首发、正式量产、小批量交付、投产仪式

**medium**：增资、扩建、二期、三期、备案、立项、投产在即、设备采购、产能扩张、在建、预计投产

**weak（只作辅助，不能单独成立）**：订单、采购、合作

泛动作词不足以定性，要配行业专有词一起看。

## 好源清单

| 源类型 | 特征 | 为什么好 |
|---|---|---|
| 项目立项库 / 工程信息平台 | 按「立项 / 计划开工」结构化收录 | **最早**。备案当天就进库，带计划开工时间与设备投资额 |
| 地方政府重大建设项目公示 | 公示栏目、备案栏目 | 带投资额、产能、建设起止时间，最实 |
| 地方 / 园区新闻 | 「XX 项目正式开工」「智能装配线改造投产」 | 公司名 + 投资额 + 开工时间齐全 |
| 上市公司公告（巨潮等） | 募投、技改、增资建基地 | 标题信息密度最高 |
| 财经媒体、投资者关系记录 | 在建产线进度、产能规划、预计投产 | 补政府公示与公告的盲区 |
| 中央级媒体地方频道 | 有具体产线、节拍、产品 | 信息可比对 |

## 坏源清单（实测失效，不要浪费时间）

| 源 | 问题 |
|---|---|
| 企查查 / 天眼查 档案页 | 静态资料，无近期动作（招投标、行政许可板块除外） |
| 行业门户首页 | 「XX 大会开幕」「标准化工作会议通知」，零线索 |
| 公共资源交易中心首页 | JS 渲染，HTML 里没有标题 |
| 部分地区交易平台 | 域名解析失败 / 302 重定向循环 / JS 空壳页 |
| 政府采购网关键词搜索 | 连续访问返回「频繁访问」拦截页 |
| 中标栏目 | 主体是采购人（甲方），与买家相反 |
