# 轴承厂产品画像表（空模板）

**这张表是空的。技能里不带任何成品画像——必须由用它的那家轴承厂自己填。**
原因很简单：拿一套编出来的画像跑，出来的线索不是它的生意。它会当场看出「这家不归我们做」，然后就不再用了。

> 表里填的是**轴承厂自己**的产品能力（做什么类型、什么尺寸、什么精度），不是下游客户的资料。填错对象，整套判断都会跟着错。

---

## 一、交给轴承厂填的表

把下面这张表整段发给轴承厂，让它填完发回来。**第 1–5 项必填，其余空着没事。**

```
轴承下游线索雷达｜轴承厂产品画像表
1. 厂名：                    （用于报告抬头）
2. 主做什么类型：            （深沟球 / 圆锥滚子 / 调心 / 外球面 / 非标）
3. 主做哪几个型号段：        （如 6200-6206、6300-6304；写不出就写内径范围）
4. 内径范围：                （如 d5-25、d15-60；不清楚就留空）
5. 主打精度：                （P0 / P6 / P5 / P4；圆锥可写 P6X）
6. 主攻哪三个行业：          （电机 / 家电 / 水泵 / 农机 / 汽车 / 输送 /
                              纺织 / 通用机械 / 压缩机 / 机器人 / 其他）
7. 明确不做的：              （如 d>60、圆锥、P5 以上——填了能少推错）
8. 最近三个月成交最多的三类下游：（这条比第 6 条准，能填就填）
```

---

## 二、每项怎么填（给轴承厂看的说明）

### 1. 类型

看代号首位：`6` 深沟球 / `3` 圆锥滚子 / `N` 圆柱滚子 / `U` 外球面 / `2` 调心滚子 / `7` 角接触 / `5` 推力球 / `1` 调心球。

**一家厂常常做两三类。** 全填上，但要标出哪类是走量的。

### 2. 型号段

这是最有信息量的一栏，也是最能筛掉不匹配线索的一栏。

写实际出货的段，不要写「全系列」。比如：

- 深沟球走量：6200、6201、6202、6203、6204、6205、6300、6302
- 圆锥：30206、30207、30305、32206
- 外球面：UC204–UC210、UCP204–UCP210

写不出来就跳过，用第 3 项的内径范围代替。

### 3. 内径范围

内径代号换算：**右起两位数字 × 5 = 内径 mm**；`00/01/02/03` 分别 = 10 / 12 / 15 / 17 mm。

例：6205 → 内径 25 mm；6308 → 内径 40 mm；30206 → 内径 30 mm。

填范围就行，「d5-25」比一串型号好写。

### 4. 精度

| 等级 | 常见场景 |
|---|---|
| P0 | 普通电机、家电、输送、农机、通用机械 |
| P6 | 电机、减速机、泵、汽车轮毂 |
| P6X | 圆锥专用（农机、汽车、重载） |
| P5 | 机床主轴、印刷机、压缩机 |
| P4 / P2 | 精密主轴、硬盘、高速电主轴 |

**精度是硬门槛，不是加分项。** 做 P0/P6 的厂，碰到 P5/P4 的线索会直接判 0 分——报了也做不了，试一次就再也不信这个工具。

### 5. 主攻行业

**最多三个。** 这是硬规则，理由：超过三个等于没筛。

说不出三个就问：**最近三个月成交最多的是哪三类下游？**

按成交反推比按产品目录准——产品目录写「可配套电机、家电、汽车、农机、工程机械、纺织、矿山、风电」，实际成交可能 80% 在电机。

### 6. 明确不做的

这一栏最有价值，因为它能挡掉一半误推。

常见填法：「不做 d>60」「不做圆锥」「不做 P5 以上」「不做风电偏航」「不做出口型号」。

## 三、拿到画像之后

1. **记在会话里**，下次直接用
2. **换一家轴承厂必须重填**，不要拿 A 厂的画像跑 B 厂要的线索
3. 轴承厂改过一次画像，就把新版本记下来，覆盖旧的
4. 一家跑过三五次之后，可以回头问它：「上次给的那几条，哪几条真的跟了？」——用实际反馈调画像，比什么都准

---

## 四、为什么不预置几套成品画像

预置画像看起来省事，实际上是把这个技能变成玩具：

- 轴承厂第一次看到线索，会问「这是按我们厂跑的？」——只能答「按同类厂常见配置跑的」
- 报错一次，它就不会再给第二次机会
- 而且预置画像里那些型号段、精度，是编的，不是它厂里的

**没有画像就不跑，是这套东西唯一诚实的开场。**
