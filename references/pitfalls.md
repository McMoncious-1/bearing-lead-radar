# 踩过的坑

每条对应一次真实误判。命中就丢，或降级为待确认。

## 一、串词

| 坑 | 案例 | 修法 |
|---|---|---|
| 「家电」藏着「国家电投」「国家电网」「国电投」「国家电力」 | 电表厂被判成家电厂，给了 96 分 | 命中即排除，不参与行业判定 |
| 「叶片」 | 风电叶片厂被当风机厂 | 叶片厂是复合材料件厂，不买轴承 |
| 「齿轮」 | 齿轮厂被当减速机厂 | 齿轮厂是零件厂，不是整机厂 |

原则：行业泛词（家电、电机、汽车）单独出现不足以定性，至少要 1 个专属词，或 2 个泛词互相印证。

## 二、名字像工厂，实际不生产

公司名里出现这些词，基本可判为非制造主体：

> 环保 / 环卫 / 环境 / 水务 / 燃气 / 热力 / 置业 / 物业 / 供应链 / 贸易 / 商贸 / 设计院 / 研究院 / 检测 / 咨询

公告的业务描述里出现这些词，说明它在「干活」不是「造件」：

> 合同能源管理 / 节能改造 / 建设运营 / 综合服务 / 运营服务 / 总承包 / 工程总承包 / 咨询服务 / 运维服务

案例：城发环境、中原环保——抓到的是「生活垃圾分拣中心」，而它们是环卫服务商；智光电气——「给水泵节能改造合同能源管理」，是改造服务商，不买轴承。

## 三、假扩产（动作词对了，方向反了）

| 假信号 | 为什么假 |
|---|---|
| 转让生产线、出让产能指标、产能置换 | 卖产能，不是加产能 |
| 调整生产线摆放位置、产线布局调整 | 挪机器，不是买机器 |
| 停产、关停、终止 | 反信号 |
| 关联交易、担保、回购、增持、减持、分红、股权激励、业绩说明会、审计报告、股票异常波动 | 资本市场动作，与生产无关。上市公司公告里这类占大头 |

## 四、中标的主体错位

中标公告的主体是**采购人（甲方，买东西的）**，不是中标人（造设备的）。真正可能买轴承的是中标人，名字在详情页正文里，不在标题。

案例：「某高校工业机器人实训平台设备更新采购项目中标结果公告」——一所大学在买设备，与轴承无关。

处理：只在能确认「中标人是制造企业」时才用，否则不上台面。

## 五、热词 + 零部件 = 供应商

| 对象 | 抓到什么 | 为什么不是买家 |
|---|---|---|
| 模塑科技 | 人形机器人外覆盖件订单 | 做外壳件 |
| 立中集团 | 人形机器人加工件定点 | 做加工件 |
| 富临精工 | 人形机器人应用项目合作 | 投资/合作，不是自己造 |

规律：**热词 + 零部件 / 加工件 / 合作 / 应用 = 供应商。**

更隐蔽的一种——标题全是扩产动作，读下去才发现是件厂：某电机部件厂（江苏靖江）「增资扩产，新增 6700 平方米厂房，柔性自动化产线」，实际做铝合金电机机壳和散热器，客户是整机厂，**它买的是别人的轴承**。公司名里带「部件」「配件」「组件」「结构件」「机壳」「壳体」的，先怀疑。

## 六、静态页不是源（一个例外）

企业档案页（企查查、天眼查）的「经营信息 / 企业简介 / 工商信息」是静态资料，没有近期动作，看到就丢。

**例外：企查查的「行政许可 / 招投标 / 新增建设项目」板块有真动作。** 挖到过某汽车电机厂（湖北）的「油泵电机自动装配线改造项目」，总投资 2500 万、建成后年产 100 万台（环评批复 2026-10-16）。带投资额、产能、批复文号，质量高于大多数新闻稿。**要用，但必须进原文确认事件日期**——页面上的「更新时间」是抓取时间。

企业官网的「关于我们 / 生产基地 / 集团概况」最隐蔽：会把旗下所有基地的投产年份列一遍，看起来信息量极大，其实全是旧闻且永不更新。案例：某泵业官网把四个基地（2003 / 2020 / 2024 / 在建）列在一起，抓下来像四条线索，实际一条新的都没有。

判断标准：**这个页面会随新事件更新吗？不会就不算源。**

## 七、一条公告被多家转载

同一条公告会被券商、财经媒体、地方网站各发一遍。按「公司名 + 事件核心词」判重，不要按标题字面判重。
