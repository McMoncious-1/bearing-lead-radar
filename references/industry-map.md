## 读这张表的三个要点

1. **精度是一票否决项。** 只做 P0/P6 的厂，看到机床、风电、印刷机、硬盘，直接 0 分——不是行业不热，是这活他接不了。
2. **普通行业绝大多数停在 P0/P6。** 电机、减速机、输送、农机、家电，这些才是走量的地方。别被「高精尖」三个字带偏。
3. **尺寸段决定重合比例。** 画像覆盖 d5–25 的厂，去做工程机械（30–120）就是错配；反过来做家电、电机、小泵是刚好。

## 尺寸对照（常被引用，直接可用）

- 深沟球：6205 = d25×D52×B15；6308 = d40×D90×B23；608 = d8×D22×B7
- 圆锥滚子：30206 = d30×D62×T17.25
- 外球面：UC205 = d25×D52×B34.1

内径代号规则：型号右起两位 = 内径 / 5；**00/01/02/03 例外，分别对应 10 / 12 / 15 / 17 mm**。

类型代号：6 深沟球、3 圆锥滚子、N 圆柱滚子、U 外球面、2 调心滚子、7 角接触、5 推力球、1 调心球、0 双列角接触。

精度等级：P0（省略）/ P6 / P6X（仅圆锥滚子）/ P5 / P4 / P2。
游隙是另一套独立代号：C1 / C2 / CN（省略）/ C3 / C4 / C5，**不要和精度混在一起说**。
