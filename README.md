# 轴承下游线索雷达（Bearing Lead Radar）

面向轴承制造企业的下游客户线索检索技能，部署于豆包客户端本地工作区。

| 项目 | 说明 |
|---|---|
| 当前版本 | v0.1.0 |
| 发布日期 | 2026-11-11 |
| 适用平台 | Windows，豆包客户端（工作模式） |
| 运行方式 | 本地技能目录加载，按需调用 |
| 依赖 | 无。纯文本技能，不含可执行程序、数据库或服务端 |
| 著作权人 | 云衍科技（洛阳）有限公司 |

## 一、功能概述

轴承销售环节的难点通常不在于缺少企业名录，而在于无法判断目标企业当前是否处于设备选型与供应商准入阶段。企业在项目开工、产线建设、投产前后的一段时间内存在明确的轴承采购需求，该窗口期一般持续数月；一旦进入量产稳定期，供应商体系即基本固化，重新进入的成本显著上升。

本技能从公开信息中检索近期存在扩产、开工、建设、投产等动作、且自身为整机生产主体的下游企业，依据轴承企业的产品类型、尺寸段与精度能力计算适配评分，并输出可核验的原始信息来源链接。

输出内容为线索与判断依据，不含联系方式。

## 二、工作原理

全流程基于联网检索与人工规则判断，不含爬虫程序。共九步：

| 步骤 | 内容 |
|---|---|
| 1 | 采集轴承厂产品画像。未取得五项参数不进入检索 |
| 2 | 解析参数。时间范围、行业、地区、条数、分数门槛，未指定时按默认值执行 |
| 3 | 生成检索式。检索对象为"近期有投资或建设动作的企业"，而非"轴承客户" |
| 4 | 并行检索。单轮三组检索式，按标题信息密度初筛 |
| 5 | 时间过滤。按事件发生日期取舍，不按文章发布日期 |
| 6 | 主体判定。区分整机制造企业与零部件配套企业，此步决定结果有效性 |
| 7 | 适配评分。四维匹配（行业 35、产品类型 25、尺寸段 20、精度 20，精度不匹配直接判零），再乘时机系数（设备采购 1.0 / 土建施工 0.85 / 备案待开工 0.8 或 0.6 / 试产 0.75 / 已量产 0.4） |
| 8 | 剔除。去除串词误配、名义扩产、非制造主体、服务型业务与静态档案页 |
| 9 | 输出。单次 2–5 条，每条附来源链接与判断依据 |

## 三、环境要求

- Windows 操作系统
- 已安装豆包客户端，并启用工作模式
- 客户端具备联网检索能力，且剩余额度充足
- 本地存在技能目录：`...\.doubao\agent_mode\workspace\.user_skills\`

技能目录为硬性前提。该目录不存在时无法部署，本版本亦不提供其他安装路径。

## 四、安装

本版本仅支持手动部署，步骤如下：

**第一步：复制文件夹**

将 `bearing-radar` 文件夹整体复制到技能目录：

```
%LOCALAPPDATA%\Doubao\User Data\Default\.doubao\agent_mode\workspace\.user_skills\
```

完整路径示例：

```
C:\Users\<用户名>\AppData\Local\Doubao\User Data\Default\.doubao\agent_mode\workspace\.user_skills\bearing-radar\
```

**第二步：重启客户端**

完全退出并重新启动豆包客户端。技能在客户端启动时加载，未重启不生效。

本仓库不提供命令行安装方式。`npx skills` 一类 CLI 的安装目标为其他 agent 客户端的技能目录，与豆包客户端的加载路径不兼容，安装后不会被识别。

## 五、安装验证

重启客户端后，向助手发出任一检索请求：

```
查一下近 7 天的轴承下游线索
```

预期现象：助手不直接开始检索，而是先询问五项画像参数。本技能不内置任何预置画像，该反问行为即为加载成功的判据。

如助手直接进入检索且未询问画像，说明加载的为旧版本或文件不完整，请检查 `references/轴承厂画像表.md` 是否存在。

## 六、使用说明

首次使用时一次性提供完整画像：

```
深沟球，6200-6206 加 6300-6304，d5-30，P0/P6，主攻电机、家电、水泵，查近 7 天
```

未指定时间范围时按近 30 天执行。

同一家轴承厂再次检索时可省略画像：

```
还是那家，查近 30 天，只看电机和水泵
```

更换轴承厂时须重新提供全部五项参数：

```
换洛阳那家：深沟球，d10-40，P0/P6，主攻电机、农机、水泵，近 30 天，给 5 条
```

### 五项画像参数

| 序号 | 参数 | 填写说明 |
|---|---|---|
| 1 | 类型 | 深沟球、圆锥滚子、调心、外球面、非标 |
| 2 | 型号段 | 如 6200-6206、6300-6304；无法确定时填写内径范围 |
| 3 | 内径范围 | 如 d5-25、d15-60 |
| 4 | 精度 | P0、P6、P5、P4；圆锥滚子可写 P6X |
| 5 | 主攻行业 | 不超过三个。回复"什么都做"时，改问最近三个月成交最多的三类客户 |

## 七、输出规格与能力边界

| 项目 | 实际情况 |
|---|---|
| 单次条数 | 2–5 条，取分数最高者，不凑数。默认时间范围为近 30 天；近 7 天窗口通常仅 2–3 条。同类工具常见的 20 条以上口径不适用于本技能 |
| 检索口径 | 政府公示、项目立项库、上市公司公告、财经媒体四路并行。单一路径会漏线索：仅靠政府公示会漏掉投资者交流披露的在建产线，仅靠财经媒体会漏掉县级项目公示 |
| 信息覆盖 | 以政府项目公示、环评批复、上市公司公告为主；非上市整机企业覆盖有限 |
| 联系方式 | 不提供。不输出手机、微信、邮箱等任何个人联系方式，仅提供公开信息链接 |
| 推送 | 不支持定时推送，按需调用 |
| 客户管理 | 不含跟进记录、报价、开发信等功能 |
| 空结果处理 | 检索参数过窄时返回空结果并说明原因，不做数量补足 |

本技能的典型使用方式为按需调用并输出结果，不需要长期驻留运行。
